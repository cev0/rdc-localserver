# PvP snapshot mərhələsi

- Server-authoritative hücumçu snapshot helper-i əlavə edildi.
- Müdafiəçi üçün aktiv səfərdəki konvoy qoşun/qəhrəmanlarını baza müdafiəsindən çıxaran snapshot helper-i əlavə edildi.
- Mövcud PvE qoşun gücü formulası təkrar istifadə olunur.
- Real PvP resolver, itki, loot və iki oyunçu state mutation-u bu mərhələdə qəsdən aktiv deyil.
- Mövcud `pvpEnabled=false` və `canAttack=false` davranışı dəyişmir.
